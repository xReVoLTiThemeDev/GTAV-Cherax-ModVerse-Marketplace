# ModVerse Vehicles thumbnails

Approved vehicle screenshots are stored here as `<catalog-id>.jpg`. Each must match `thumbnail_sha256` in `marketplace/vehicles/catalog.json`.

To upload a thumbnail in the GitHub web UI, open this directory, click **Add file → Upload files**, choose the matching `.jpg` file, and commit to `main`.

Do not rename the image to its local installed vehicle filename (`mMV_...`). The Cherax client requests thumbnails by catalog ID.
